Introdução ao JavaScript

O que é o JavaScript?

É uma linguagem de programação muito utilizada para criar aplicações interativas e sistemas de software.

Ele é responsável por:

  • Responder a cliques
  • Validar formulários
  • Atualizar conteúdos
  • Buscar dados de APIs
  • Controlar o comportamento da aplicação

IMPORTANTE: JavaScript não é Java. Apesar da semelhança nos nomes, são linguagens totalmente diferentes, com características e escossistemas próprios.

Curiosidade: Foi criado em apenas 10 dias.

O que dá pra fazer com JS?

  • Frontend:
    • Criar interfaces interativas
    • Menus
    • Validações
    • Filtros
    • Animações
    • Dashboard
    • Aplicações com React, Vue, Angular, Astro e etc.
  • Backend:
    • Nodejs
    • Criar APIs REST
    • Autenticação
    • Processar requisições
    • Integrar com serviços e com banco de dados
  • Mobile/Desktop:
    • Criar aplicativos
    • React Native e Electron
